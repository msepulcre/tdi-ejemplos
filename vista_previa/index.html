Experimentación con ejemplos

Para cada ejemplo se proporcionan dos versiones:

  • HTML estático: una página de lectura con explicaciones, código y resultados ya calculados. No ejecuta el código ni recalcula las gráficas.
  • Cuaderno Jupyter (.ipynb): permite modificar parámetros y ejecutar el código para experimentar. El botón «Abrir en Colab» lo abre directamente en el navegador, sin descargar archivos ni instalar Jupyter. Para ejecutar se necesita una cuenta de Google; las instrucciones están dentro del cuaderno.

Las fórmulas de estas vistas HTML utilizan MathJax y pueden requerir conexión. Las gráficas están incluidas en cada archivo.
